# Django Source Reference

**Classification:** Upstream framework reference · **Status:** Preserved source snapshot

This repository contains a copy of Django's upstream framework source and history. It is not, by itself, evidence of a standalone personal Django application.

- The original Django project documentation remains in [README.rst](README.rst).
- Django package metadata is defined in `pyproject.toml`.
- Review commit authorship and repository history before attributing framework changes to this repository owner.

The `djangoportal` repository contains matching Django project metadata and should be compared carefully before either repository is consolidated or archived.
